# FillTwo

Two-bar live fill desk for bedroom producers and AI-music finishers.

Suno and loop DAWs reprint the pocket forever. The loop never hands off because there is no fill.
Session players write two live bars — snare roll, bass walk, nylon answer, brass stab, tom fill, stop hit — so the next section can land.

Live samples only — FluidR3 acoustic grand, upright bass, nylon guitar, trumpet, violin, and acoustic kit from the PreEight sample CDN pinned to commit SHA.
No oscillators. Audio never leaves the tab.

## Distinct from yesterday and the rest of the line

| Tool | Job |
| --- | --- |
| TagFour | Four-bar last-line tag after the money chorus |
| ModEight | Last-chorus key change |
| LiftTwo | Two bars of climb *into* the hook |
| PreEight | Eight bars *before* the hook |
| AfterHook | Eight bars *after* the hook |
| EndEight | Last eight bars of the record |
| LastHook | Last chorus is the money chorus |
| **FillTwo** | Two bars of live *fill* that break a looping pocket so the next section has a door |

Not a pre-hook lift. Not an ending tag. Not a key change. Not a full pre-chorus.

## Form

1–6 pocket · 7–8 fill · next section lands on 9

## Play

- A · Pocket loop (the dump)
- B · Pocket + fill
- 2 · Fill only (for the export)
